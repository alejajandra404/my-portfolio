# Portafolio Personal — Alejandra

One-page portfolio construido con React + Vite. Ver [CLAUDE.md](./CLAUDE.md) para el brief de contenido y estructura.

## Desarrollo

```bash
npm install
npm run dev
```

## Estructura

```
src/
  components/
    Navbar/
    sections/
      Hero/
      About/
      Experience/
      Stack/
      Projects/
      Footer/
  App.jsx
  main.jsx
  index.css
```

Cada sección corresponde a un bloque del brief de contenido (`CLAUDE.md`). Los textos marcados como placeholder aún están pendientes de redacción final.
